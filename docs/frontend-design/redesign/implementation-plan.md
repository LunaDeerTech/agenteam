## 3. 所有阶段共用的实施与退出规则

- **输入明确。** 记录基线、当前路由、真实数据/操作能力、参考样板和唯一写者。M3 功能分支成果必须先取得实际集成代码，不从历史状态表拼页面。
- **展示层重构充分。** 允许重新组织 template、页面组件、样式、共享 UI 与页面组合，拆分过长展示职责；不承诺旧组件逐字保留。优先复用 API client、composable、请求协调者、Session/Project guard、DTO 解码和领域状态机，不顺手重写请求/幂等/取消协议。
- **真实业务不缩水。** Owner 与 admin 边界、七状态、归档/删除、原版本/字段 presence、Unknown 原 key、迟到结果、Secret 不回显等以架构与对应工作项为准。视觉调整不能减少真实风险门。
- **同输入看整页。** 对照同 fixture、同 viewport、同主题与相同展开状态的旧页/新页；代表完整页面同时检查真实内容、长内容和异常。Fixture 只证明视觉/特定交互，写入/授权/恢复另用相关真实链路。
- **验收按影响。** 运行受影响的工程检查和关键行为测试；共享组件变更检查其消费者。权限/完整性/Secret/Unknown 等实际风险由非作者验证。既有证据在输入未变时复用，不为改间距重跑无关全站后端矩阵。
- **退出明确。** 作者自查及适用独立审查结论齐，达到阶段视觉与功能条目，失败/未验证范围被列明，相关规范与当前状态一致。视觉失败必须返修，不能以类型检查通过代替。无需在每个子步骤请求用户重复确认。
- **回退有边界。** 各阶段以可独立回退的展示层变更交付；回退时恢复本阶段页面/组件并保留已经产生的服务端事实，不做数据回滚。共享基础与页面迁移保持兼容直到消费者切换完成；不要长期留两套全局 token 或双路由产品。

本轮只建立计划及文档检查，没有运行产品测试、改变业务契约或认定任何阶段通过。

## 4. F0：完整页面样板与视觉系统定稿

**依赖/范围：** 当前 v2 规范；实际已存在的项目列表、任务、复杂设置和内容页面。文件范围为本目录及后续指定的独立设计样板材料；若需要交互原型，使用明确归属的隔离演示入口，不接管正式路由或后端。

**交付物：** 完整项目列表、任务看板+详情、Provider/Model 设置三类样板；配套系统/项目 Dashboard、Knowledge 阅读与窄屏结构。输出浅深主题、桌面与390px关键页，使用真实字段构造的明确合成数据；同时覆盖长名称、空态和错误。先建立中性表面与字体层级，再比较少量强调色候选，最终形成一套可实现的 token/布局/动作方案。

**视觉验收：** 每个样板明确映射 L1—L8 的相关结构；不是只有色板、组件墙或截取局部。主内容、状态、主动作可立即辨认；三类页面使用同一系统仍有适合任务的密度。Dashboard 有用且没有虚构聚合指标，任务首屏由任务主导，设置不叠成 API 字段墙。

**功能验收/退出：** 每个动作标注已有命令或依赖，布局承载加载/失败/只读/Unknown，关闭/键盘设计可实现。样板与 token 决定明确记录，后续可以直接实施；未实现原型不宣真实功能通过。无需把每个视觉细节变为单独用户审批。

**非目标/回退：** 不做全站产品迁移、不增加业务能力、不冻结未经完整页面验证的色值。候选不合格时在样板范围调整，不影响现有产品。

## 5. F1：共享基础、应用框架及项目列表样板

**依赖/文件范围：** F0。`web/src/styles/`、`components/ui/`、`components/layout/`、App/SystemNav/ProjectNav/SettingsShell 的实际归属文件、项目列表页及相关呈现测试；API/composable 仅在视图拆分确有必要时最小适配，不更改命令语义。

**交付物：** v2 语义 token、字体/表面/选中/动作层级；系统与项目 header、view bar、集合/表单/工作台组合；按实际需要增强 Dialog/Drawer/菜单/segmented 控件；项目列表成为首个真实页面样板。同步 v2 最终采用值，旧视觉规范只留历史入口。

**视觉验收：** 浅深主题都有表面层次与清楚焦点；不靠同等边框按钮表达所有动作；1440/390/1920px 对照 F0，名称列、筛选、主动作与分页稳定；正常项目页系统/项目导航不出现无信息用途的额外空行。最终 token 对比度实测达到目标。

**功能验收/退出：** 真实导航/直接链接、项目创建原接受→就绪条件、查询/分页/恢复保持；Dialog 锁焦点、Escape/关闭门禁和回焦，菜单键盘、200%缩放/减少动效/长内容通过对应检查。共享改动的代表消费者可运行；项目列表样板获得独立视觉/交互审查后再推广。

**非目标/回退：** 不一次修改所有业务页，不引入全局搜索/Inbox假入口。保持过渡消费者兼容，失败回退本批展示层和 token；不改服务端事实。

## 6. F2：Dashboard、项目概览与账号入口

**依赖/文件范围：** F1；`HomeView`、`ProjectHomeView`、四个账号入口和认证布局、必要首页数据复用。真实账号/项目 client 与守卫保持。

**交付批次：** F2a 系统首页/项目概览；F2b 登录/邀请/找回/重置。系统首页复用 Owner 目录形成入口，项目概览复用 Project 资料/状态，解除旧空容器设计。

**视觉验收：** 首页首屏已有明确可用入口和状态；没有“大空框+标题”、虚构指标或无持久能力的“最近访问”。四个认证页目的和主动作统一，390px、长错误、挑战出现时结构不破；敏感技术材料不占正文。

**功能验收/退出：** 初始密码提示与合法返回保持；真实 Session/匿名 CSRF/挑战及邀请/reset失败流程按影响验证。首页列表独立空/失败可恢复，不泄露旧身份项目；项目归档/无权限状态正确。首页、项目概览及四个账号页共六个入口按对应路由逐项登记完成，不以认证壳一张图代证。

**非目标/回退：** 不新增统计/活动流/最近访问服务、身份产品或生产 SPA 发布。可分别回退首页与认证两个批次，不触碰账号数据。

## 7. F3：个人与系统设置

**依赖/文件范围：** F1；现有三个个人页、十一个系统页及领域编辑组件；SettingsShell 如需调整由既定唯一 owner 处理，不跨批私自改壳。

**交付批次：** F3a 个人三页+用户/邀请/Runner；F3b Provider/Model/用途；F3c 账号安全/SMTP/出站/审计/运行信息。每批执行相同 v2 框架，字段与命令不从旧文档猜补。

**视觉验收：** 集合、复杂配置与只读诊断三类明显区分；Provider→Model→Credential 不再纵向无尽追加。设置分区有清楚标题/帮助/控件关系；实际 ready=false、未知、投递错误保持原含义，390px 菜单和详情可往返。

**功能验收/退出：** 资料改名影响、头像、主题持久化、密码/Session；邀请投递；Runner凭据；模型类型/引用替代/用途独立版本；SMTP保存与测试；结构化审计查询和出站限制按本批受影响行为验证。凭据不回显，权限改变撤下旧内容，Unknown/冲突恢复无退化。14个现有叶子逐项覆盖。

**非目标/回退：** 不增加 MFA、用户管理新权限、未实现 MCP/模板/检索配置等新页。按栏目批次回退展示层，保留已保存配置和请求材料。

## 8. F4：项目设置

**依赖/文件范围：** F1；十个已有项目设置叶子、相应实体编辑与详情组件；复用 ProjectContext、各领域 API/composable 和请求协调者。

**交付批次：** F4a 基本信息/Scheduler/审计/调用记录；F4b Variables/Secrets；F4c Agents/Skills；F4d Project Provider/可用模型。调用记录明细与按日汇总都纳入，不按历史旧布局漏掉已有能力。

**视觉验收：** 目录→对象→编辑模式一致；技术身份退后，Agent 按用户任务分区；Secret 不出现暗示明文可读的展示；Usage 当前模式明显，数值含义清楚；危险区与日常保存分开，复杂详情有足够空间。

**功能验收/退出：** Owner、归档只读、删除确认与停止生命周期；普通变量字段 presence/空值；Secret原意图与不泄露；Agent合法模型/挂载/授权；Skill安装/分配/固定revision下载；模型替代；近30天窗口、分页、unknown/零/大整数与真实汇总语义逐批保真。十个叶子在桌面/窄屏及适用错误恢复下可操作。

**非目标/回退：** 不新增成员/角色、越权管理员入口、市场、MCP/Memory未集成页面或额外执行权限。每批独立回退展示层，不能清除真实凭据/变量/配置来回退 UI。

## 9. F5：任务工作台与任务详情

**依赖/文件范围：** F1与F0任务样板；`ProjectTasksView`、`components/work/` 的看板/详情/规划/执行呈现；原 Work/Execution composable 和领域协议保持。

**交付物：** 三个路由共用的紧凑范围/视图栏、看板与卡片、上下文规划任务、结构化详情、适用的当前动作与恢复区域。先完成现有 Kanban，不把 Explore 的新功能混作完成条件。

**视觉验收：** 使用本轮同内容 fixture，1440×960 的第一张任务卡目标在 y≤340px，390×844 在 y≤420px；这是本项目针对正常有数据状态的验收目标，不是 Linear 数字。首屏不被规划/搜索帮助占满；看板局部横滚、无 document 横溢。详情描述与状态先于管理动作群，执行/依赖/历史可定位。出现真实必须告知的错误/等待时优先完整呈现，不裁文案硬凑坐标。

**功能验收/退出：** 默认/指定Sprint、任务直链、七状态、排序/规划、指派/评审、Blocker/依赖、成果/Execution/审批/取消/时间线等现有行为不丢；Unknown原请求、未保存草稿、关闭/返回/权限切换和迟到结果覆盖受影响路径。非拖拽操作、键盘详情与窄屏往返可完成真实任务旅程。

**非目标/回退：** 不改状态机、不开放未允许拖动、不重写执行协议、不新增 Explore 业务。看板与详情批次可分别回退，但稳定对象导航和命令恢复必须兼容。

## 10. F6：知识库与产物工作台

**依赖/文件范围：** F1；Knowledge/Artifact 页面、树/阅读/编辑/预览组件及必要安全渲染适配；已有 API、分段读取、下载与草稿协议保持。

**交付物：** 清楚的文档 header、稳定目录、正文优先的阅读/编辑空间；连续产物列表、格式化元信息与真实支持的预览；如引入 Markdown 渲染，单列安全实现与必要依赖变化。

**视觉验收：** 同样本390×844正文目标在 y≤380px；与旧约640px对照，次要管理动作不堵住阅读。1440px中文行宽适当，代码/表格局部滚动，目录状态清楚，产物时间/大小可扫读。无格式支持时的诚实说明与可用动作同样作为成品检查。

**功能验收/退出：** 目录展开/选择、已有标题搜索范围、指定文档链接、完整读取/分段、原文编辑、移动/子树删除、草稿/Unknown/版本冲突、权限变化/返回焦点保真；安全Markdown不执行原HTML或绕过资源策略。文本产物创建和读取、非文本不支持预览、取消与下载按当前实际能力验证。

**非目标/回退：** 不新增跨项目搜索、富文本协作编辑或假的媒体支持；安全渲染无法达标时保留明确原文阅读模式，不宣完成该增强。可分别回退读取呈现和编辑容器，不能变更存储正文格式。

## 11. F7：新集成能力的设计适配

**依赖/文件范围：** 每个模块单独开始。先核实际被集成的 M3/后续代码、路由、API 与接受边界，再确定 Meeting/Inbox/MCP/Memory/其他待接栏目对应文件 owner。不能从旧状态记录宣称本地已存在。

**交付物：** 按[待集成覆盖](page-blueprints.md#6-当前无本地正式路由的目标覆盖)将真实模块纳入 v2。Meeting 的消息/输入为主，Inbox 的决策依据和动作相邻，MCP目录/连接/认证状态分清，Memory沿已有授权阅读能力呈现；每个模块有自己的完整页面样板与迁移说明。

**视觉验收：** 使用与已迁移页面一致的 shell/密度/动作/状态体系，同时保留模块专属主任务。无动作能力时不出现假按钮，无数据能力时不展示假数字。不得把会议改成缺少消息语义的 Issue 表格。

**功能验收/退出：** 复用该实际输入的既有业务证据，补受影响视图/焦点/状态/订阅退出与真实旅程；各子模块独立记完成，未集成项保持未开始/依赖未就绪。不把“所有规划栏目都画了”当真实接入通过。

**非目标/回退：** 不由设计任务创造 Search/Explore/模板等业务契约，不解除原 M3/生产 STOP。按模块回退 UI，不撤销已发生的 Decision/Proposal/连接/执行事实。

## 12. F8：全站一致性与连续旅程验收

**依赖/文件范围：** F2—F6及实际已完成的F7子项；受影响页面、共享组件、必要定向测试和v2规范。此阶段首先验收，缺陷回原 owner 修复，不重新开启全站设计探索。

**交付物：** 对36个现有叶子的覆盖结论、已集成增量的独立记录；同数据的完整页前后对照；跨页旅程与剩余缺口；v2的最终实施值和旧规范历史导航一致。

**视觉验收：** 首页→项目列表→项目空间→header menu 的层级完整；代表集合/看板/阅读/复杂设置在两主题、390/834/1024/1440/1920及200%缩放选样通过，边界/排版/动作/选中没有局部旧风格残留。没有页面级横溢、被遮挡的提交/关闭、无意义卡片墙或主要内容被技术操作淹没。

**功能验收/退出：** 至少跑通系统首页进入项目并打开具体任务、任务详情返回来源、知识阅读编辑及返回、复杂设置编辑与明确失败恢复、账号/项目切换撤下旧内容。真实风险门按影响补齐，固定输入已过证据复用。新问题有明确责任与限制；重大视觉/导航/业务退化未关闭则不能宣告迁移完成。

**非目标/回退：** 不以尚未集成的F7功能或生产SPA发布作为既有页面验收失败，不冒称整个产品ready。发现共享退化时回退明确有问题的批次/组件并复验其消费者，保留已经通过且无依赖变化的页面。
