## 本轮边界与文档优先级

本轮进入新 Vue 工程实施。新工程不复用归档前端的 API 客户端、Session、权限或业务实现；必要后端接口随具体页面任务重新设计。本轮只交付共享 UI、框架和路由骨架，不迁入完整 Agent 或项目列表正文，不补造系统设置表单、业务数据、认证授权或后端结果。运行与工程边界见[前端开发说明](../../development/frontend/README.md)。

Agent HTML 和旧前端只提供产品/视觉对照。原样板使用合成数据，其浏览器结果、旧真实前端的验收和新工程检查分别保留；本轮不继续扩展 HTML 功能，也不把原型源码直接移植为新 Vue 业务实现。

后续重设计任务按以下顺序使用来源：

1. 用户本轮方向及固定信息层级；正式架构中的权限、生命周期、数据完整性和恢复约束。
2. 本目录重新建立的 **v2 正式设计规范**：信息结构、页面组合、组件职责和状态/交互规则是返修起点；受用户反馈影响的结构与第 8 节视觉值待完整页面重新验证，不能继续当作已接受基准。
3. 正式架构与已确认产品要求定义目标；旧源码和工作项帮助核对历史含义。新页面的数据、接口、状态和权限合同随页面重新设计，旧实现不限定新工程，也不因未接入而删减已确认目标。
4. 旧视觉规范、CSS token 与 Debug 组件只作历史参照，不复用其实现；不能以“符合旧规范”判定新设计合格。

旧规范保留为历史材料；[处置矩阵](audit.md#4-旧规范处置矩阵)解释被替代的视觉策略和继续有效的业务约束。本轮直接建立 v2，不逐条修补 v1。F0/F1 校准 v2 视觉值并同步实际 CSS/组件；旧青蓝强调色、26px 标题、统一尺寸和包豪斯表述不再约束新设计。新规范是后续工作的正式来源，不表示样板已验收或产品已迁移。

## 实现快照与后续集成

以下保留原前端与 F0 的历史范围；文中旧路由/Session/客户端位于 `web-crape/`，不是新 `web/` 已实现或必须复用的合同。新工程接续按[当前执行计划](implementation-plan.md#1-阶段总览)。

原 `ce2f8467` 快照有 36 个正式叶子定义；原 11 个正式路由、17 个视口/主题组合的 fixture 视觉抽样继续作为历史证据，不改写为新主线的全站覆盖或通过结论。现行[页面蓝图](page-blueprints.md)已按 `3fc44101` 的增量更新为 **40 个正式叶子（36+4）**，项目设置由10增为11叶；3个重定向、404和开发 `/debug` 不计入正式叶子，Agent Memory是内嵌面板而非新路由。

**主线衔接：** `origin/main@3fc44101` 已包含正式交付的 M3，接受范围见 [M3 工作项](../../development/work-items/m3-knowledge-memory-collaboration.md)。新主线路由已有项目 `meetings/:meeting_id?`、`inbox`、`settings/mcp` 及 `/mcp/oauth/callback`；Agent 设置已有 Memory 面板，不能再称这些功能在当前 main 不存在。此前主线衔接仅据新 router、Agent 页面和正式 M3 摘要核对这项变化，没有重新进行产品或全站视觉验收。全局搜索、Task Explore 等其他目标仍按实际代码和契约判断。

此前 F0 已按当时 API 与页面核对新增页面/面板，并制作独立样板；F1—F6 按当前导航/Session协调、MCP工具审批、Knowledge四格式文件及PDF能力修订保真要求，F7明确负责现有Meeting、项目Inbox、MCP/OAuth与Agent Memory的重设计，F8依赖F2—F7并覆盖全部40叶及内嵌面板。新增样板曾纳入原 F0 浏览器检查；正式产品迁移仍须在对应实施阶段实看，不能以样板替代；这不影响沿用M3各自固定输入的既有功能证据。此前主线衔接只发布规划文档与既有技能/角色配置；原 F0 曾获得限定输入下的内部独立检查通过；用户实看后否定设计，该结论不能代表当前设计接受，当时 F0 重开且未启动产品重构；M3 的完成来自其正式交付记录，不来自本轮设计审计，原接受范围、失败和未覆盖事项保持各自含义。

## 技能与后续启动方式

后续从 [agenteam-frontend-redesign](../../../.agents/skills/agenteam-frontend-redesign/SKILL.md) 开始，由 [frontend_designer](../../../.codex/agents/frontend-designer.toml) 负责完整页面设计和样板、[frontend_visual_reviewer](../../../.codex/agents/frontend-visual-reviewer.toml) 独立检查浏览器视觉与交互，按任务复用现有 Vue 开发、测试工程与功能验证角色；具体阶段绑定见[执行计划](implementation-plan.md#2-技能与职责入口)。技能负责避免遗漏和偏离，页面效果与真实行为仍需实际验证。

当前执行顺序是 **共享 UI 与应用/设置框架 → 已定空路由 → 从系统设置逐页讨论正文与接口 → 实现和独立检查**。系统、个人和项目设置使用同一 SettingsShell，栏目差异由导航数据表达。页面未讨论前保持标题与空内容区，不能从旧实现自动恢复表单、权限或请求逻辑。

原 F0 → F1 → F2—F7 → F8 串行前置关系已被本轮决定替代；F0 全站未定稿不再阻挡 Vue 框架工作。原阶段章节保留产品目标和历史输入，当前范围、依赖与状态以[执行计划](implementation-plan.md)为准。完整页面的结构、视觉、交互和真实服务能力仍须分别取得实际证据；框架通过不能代替未开发页面完成。
