# 独立组件展示前端

2026-10-01 样式已定稿，见[样式规范](../styles/README.md)。本前端展示已确认的组件、状态和交互。保留石墨灰阶、低饱和偏蓝青蓝色、字体、密度、边界、圆角与动效。页面骨架用于承载展示，不作为正式业务页面布局依据。

打开 [index.html](index.html)，无需安装依赖或构建；支持本地文件打开。也可在仓库根目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

访问 `http://127.0.0.1:8765/docs/frontend-design/component-showcase/index.html`，支持 `?theme=dark` / `light` / `system`；默认深色。

## 文件

- `base.css`：从原预览保留的基础组件样式规则。
- `styles.css`：已选方向的语义 token、视觉与动效，沿用先前确认的参数。
- `showcase.css`：展示骨架、目录和独立样例的组织，不定义正式布局。
- `motion.js`：可中断展开／收起与退出动画，响应减少动效偏好。
- `app.js`：独立组件样例和本地演示交互，不依赖旧业务试作脚本。

## 展示范围

按钮、按钮内反馈、输入框、多行输入、校验、只读、禁用、复选框、单选、开关、下拉选择器、原生选择器、动作菜单、树、折叠执行详情、状态标签、身份点、进度、卡片、列表、表格、无头像的左右消息气泡、引用、代码、输入器、搜索、模态、详情面板、锚定说明、tooltip、加载、骨架屏、空状态、失败重试、面包屑、页签和分页。样式参数面板读取实际 CSS 值。

全部数据明确为演示；保存、复制、删除、消息与分页操作只演示组件状态，不接入 API，不定义业务能力和路由契约。原会议、任务、设置试作页及风格比较入口已移除。
