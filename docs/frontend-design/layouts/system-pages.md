# 系统首页、项目列表与 Inbox 布局

> **v1 历史布局/业务参考。** 新页面设计以 [v2 页面蓝图](../redesign/page-blueprints.md)与[目标设计系统](../redesign/target-design.md)为准；下文旧视觉、宽度和占位要求不再作为重设计约束。业务字段和流程需核对当前架构、工作项及源码，不能仅凭本历史文档判定已实现。

> 上层：[应用框架](application-shell.md)、[界面设计逻辑](../interface-design.md)。本文是布局目标，具体实现与验收按对应工作项记录。

## 1. 页面职责与区域

系统首页作为产品首页；项目列表作为当前用户进入自己项目的入口；Inbox 统一展示当前用户自己项目中需要人类处理的事项。

```text
系统导航
系统首页：页面标题 + Dashboard 占位容器
项目列表：页面标题 / 新建项目入口
          项目列表（名称、描述、进入入口）
Inbox：页面标题 / 项目与状态筛选
       待处理列表（项目、事项、摘要、阻塞、优先级、更新时间、操作）
```

## 2. 主要栏目与字段

首页只显示“首页”标题及待设计的 Dashboard 容器，不生成假数据、统计卡片或活动列表。

项目页采用[集合列表模板](../interface-design.md#9-项目列表范例与落地检查)：主区居中限宽，标题与新建主动作同排；状态筛选与轻量刷新位于工具栏，每页数量与分页在列表底部。列表使用一个容器和细分隔，每行包含项目名称、简短描述、生命周期反馈和进入入口，不将每行做成大卡片。名称也可点击进入；描述过长截断，完整内容在项目内查看。version、operation ID 保留在数据与恢复逻辑中，不占普通列表。Owner 为当前用户，列表不提供成员栏。已归档项目可识别并进入只读工作台；正在归档/删除或失败不混成已经完成，生命周期操作位于项目设置。

页面顶部提供新建项目；使用独立弹窗填写名称和描述，不在列表行或工具栏下内嵌完整表单。名称必填，描述可空；不在此引入标签、日期或成员配置。Owner 由服务端绑定当前用户，不允许表单选择。

创建已接受不等于初始化完成；只有权威结果为 ready 才能进入新项目首页。结果未知、已接受或失败时，在同一创建任务容器保留合法的查询/恢复入口，禁止自动另建或把界面关闭当作取消创建。完成后的反馈和进入遵循业务契约；关闭弹窗或切换上下文后的迟到响应不强制跳转。表单正文、独立操作区、关闭保护与焦点规则统一见[操作载体](../interface-design.md#5-操作载体与关闭规则)。

同一 Owner 下项目名不区分大小写唯一，允许英文字母、数字、连字符、下划线和点，非法路径组合仍由服务端拒绝；描述可使用中文。主页使用小写 `/{username}/{project_name}`。归档及处理中项目继续占名，永久清理完成后才释放；名称冲突保留输入，不以重试创建绕过。

## 3. Inbox 栏目与行为

点击系统导航右侧 Inbox 进入独立系统页面，不保留项目导航。普通入口汇总本人所有项目，默认 `status = open`；可按项目、来源类型、blocking 及 open / resolved / dismissed 状态筛选历史。

列表展示项目名称、title_snapshot、summary_snapshot、来源类型、blocking、priority、updated_at 和动作入口，采用 Human Inbox 的 `blocking DESC / priority DESC / updated_at DESC / id DESC` 稳定排序并分页。它是待处理投影，不是普通通知或未读消息中心。

Approval 等直接动作复用统一来源领域操作；proposed Meeting、Decision 等导航动作打开对应项目的来源页面，重新进入该项目双导航。只有 `open` 且 `dismissible = true` 的事项显示忽略入口，必须处理型事项不能忽略。处理结果由 Source Domain 保存并更新 Inbox 投影，不由前端自行标记源对象已完成。

人工审批持续等待明确处理，不因关闭页面、Session 失效、重启或等待时长自动到期；不提供自动消失或“忽略”路径。显式停止/来源删除后的取消或失效由来源领域决定，不能在 Inbox 伪造批准、拒绝或到期结果。

事项加载失败就地重试；没有 open 事项显示“暂无待处理事项”，历史筛选无结果显示筛选空状态。来源已失效或被删除时提示不可用并刷新投影；Realtime 断线后恢复订阅并重新查询权威列表。窄屏列表改为堆叠行，筛选和操作允许换行。

本人全部项目聚合是既定范围，具体查询、游标和订阅接口由责任规格落实；服务端逐项目校验 Owner，系统管理员不能看到其他用户待办。

## 4. 默认选择与导航

点击 Logo 打开系统首页；点击项目打开列表。列表不自动打开第一项。点击项目进入其 Dashboard 首页。系统管理员也只列出自己拥有的项目。

## 5. 加载及异常

列表加载显示行骨架；没有项目显示简短创建引导，筛选无结果提供清除筛选。加载失败就地重试；允许保留的旧完整数据须标明上次读取，不能冒充当前结果。创建失败保留输入并显示原因，提交中防止重复提交。对象已删除或失去访问权时撤下不可访问内容并显示说明，不把权限错误当空列表。

## 6. 窄屏

650px 以下列表行按名称/状态、描述、必要操作重排；页面工具栏和分页允许换行，标题与操作保持可达。创建弹窗适应可用宽度，正文滚动与操作区分开。复用[应用框架](application-shell.md)导航规则，不缩小字体或引入页面级横向滚动。
