# 知识库页面布局

> 上层：[项目工作台](project-workspace.md)。文档父子关系、目录查询和子树删除遵循 [KnowledgeDocument](../../architecture/knowledge-memory/knowledge-document-domain.md)。

## 1. 页面职责与示意

```text
双顶部导航
┌────────────────────┬────────────────────────────────┐
│ 新建根文档 / 查找  │ 文档标题 / 操作                │
│ 文档 A             │ 元信息 / 索引状态              │
│ ├ 文档 B           │ 正文编辑 / 正文阅读 / 文件预览 │
│ └ 文档 C           │                                │
│ 文档 D             │                                │
└────────────────────┴────────────────────────────────┘
```

左侧由文档形成树；不存在文件夹。父文档本身可有正文，选中父文档展示其内容，不展示虚拟文件夹页。

## 2. 栏目与字段

树节点显示 title、媒体类型标识、索引状态；展开箭头仅用于展开子文档，标题用于选择。默认不选中文档，右侧提示选择或新建。

右侧显示 title、source_kind、media_type、version、created_by、created_at、updated_at、父文档位置、indexing_status。内部 stored_object_id 和签名 URL 不作为用户可维护字段。

文本 / Markdown 显示阅读与编辑模式；PDF 显示预览 / 下载，DOCX 显示可用预览或下载，不提供在线正文编辑。解析未完成时保留原文件下载能力，说明可读 projection 尚不可用。

索引状态映射：pending / processing → 索引中；ready → 就绪；failed → 索引失败。索引失败不隐藏 canonical 正文或文件，提供重试索引入口；重试不增加文档 version。

## 3. 创建、重命名与调整父文档

创建表单包含标题、内容来源（文本 / Markdown 或上传支持的文件）、父文档。新建根文档预选根层；节点“新建子文档”预选该文档为父文档。父文档可为 null，每篇文档最多一个父文档。

调整父文档使用显式选择器，可选根层或同项目 active 文档；禁止自己及后代作为父节点，禁止跨项目，服务端重新校验。移动后整个后代树随父节点位置移动，正文 identity 保持稳定。

树先加载根节点，展开时按需加载子节点，同层较多时使用游标继续加载；默认按 title、id 稳定排序，不新增手工排序字段。标题查找由服务端覆盖当前项目全部合法文档并返回命中及祖先路径，不限浏览器已加载分支；它不触发全文语义检索。正文仅在打开文档时加载。

重命名编辑 title；标题/正文修改按内容 version 契约保存。仅移动父节点不增加内容 version、不重建索引，只保留当前 parent，不展示结构版本或结构历史。移动与并发删除/编辑的冲突由服务端校验，失败保留输入和选择并刷新当前位置，不把旧目录位置写回覆盖新结果。

## 4. 子树删除

删除确认显示目标文档、后代文档清单和总数量，并明确删除整个子树；取消不修改数据。确认前重新取得当前子树范围，范围变化要求重新确认，不静默扩大删除范围。

删除成功后所选文档若在子树内则清除选择，显示删除反馈；其他选中内容保持。领域需保证整个确认范围一致删除，停止 serving、清理索引和存储引用，按既有策略保留 Meeting 引用的已删除提示。失败不得把部分成功伪装为全部成功；具体事务与重试契约待补。

## 5. 默认选择、异常与窄屏

普通入口不恢复历史文档；指定文档链接选中该文档并展开祖先。展开 / 折叠不改变选择。编辑未保存时切换文档或离页使用通用未保存提示。

无文档显示创建引导；树、正文和预览独立加载并就地重试。正文冲突保留用户输入并提示重新读取；文档删除或失去访问权显示不可用状态。签名预览过期重新申请，不持久化旧 URL。

窄屏树改覆盖侧栏，选中文档后收起；工具栏换行；预览适配内容宽度。长正文和代码在对应区域滚动。
