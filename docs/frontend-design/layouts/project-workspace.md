# 项目工作台布局

> 上层：[应用框架](application-shell.md)。

## 1. 页面职责与示意

在保持系统导航的同时提供当前项目的工作入口。

```text
系统导航：Logo / 项目 / 系统设置       搜索 / Inbox / 用户
项目导航：项目名 / 会议 / 任务 / 知识库 / 项目设置
内容区域：项目首页或选中业务页面
```

## 2. 栏目与字段

项目名展示当前 Project 名称并链接项目首页；其他项按上述固定顺序排列。项目名过长截断，完整名称可查看。项目首页只保留标题与 Dashboard 容器，数据内容待定。

项目导航不增加 Agent 独立入口；Agent 管理位于项目设置。各内容页面可有自己的工具栏、侧栏、表单或抽屉。

## 3. 默认选择与跳转

从项目列表进入时打开项目首页；点击项目名返回首页。会议普通入口打开新会议准备；任务普通入口打开 Kanban 并选择 Current Sprint；知识库不默认选文档；项目设置打开首个可访问内容项。

直接链接优先指定会议、Task、Sprint、文档或设置项。浏览器返回恢复前一条导航记录所指对象；不会将未指定对象的普通会议入口解释成上次会话。

点击系统 Logo、项目列表、系统设置、Inbox 或用户显示名离开项目工作台，项目导航不再显示。Inbox 是系统级入口，在工作台中仍可访问，不受当前项目限定。项目之间不共享对象选择。

## 4. 加载及异常

先校验项目身份及 Owner，再加载内容。项目加载时显示项目名称骨架；无权限不加载子资源。子页面请求失败在其区域重试，不拆除双导航。项目不存在时提供返回项目列表入口。

## 5. 窄屏与滚动

两层导航各自横向滚动，保持固定顺序和可见的选中态；内容区占剩余高度。打开覆盖侧栏或 Task 详情不会隐藏导航对应的项目身份。
