# 产物

## 页面与访问

项目导航固定在“知识库”之后、“项目设置”之前提供“产物”，路由为 `/{username}/{project_name}/artifacts`。本页浏览当前项目中已存在的真实产物，并提供 Human 新建文本产物入口；上传、编辑及下载尚无入口。项目名称解析和每次读取都校验当前 Owner，管理员身份不豁免。归档项目按正式读取权限展示。

页面复用系统与项目双导航、共享控件和石墨灰主题 tokens。窄屏表单单列、卡片单列，长名称、摘要及校验值在容器内换行，不造成页面横向溢出。普通读取不额外引入动效；沿用共享控件的键盘和 reduced-motion 行为。

## 列表与筛选

标题、简短说明和“刷新产物”位于页首。筛选区提供“产物名称”和“产物类型”：名称按原样、区分大小写的包含查询；类型为全部、生成产物、用户上传。修改草稿不发请求，使用“应用筛选”显式提交，或“清除筛选”恢复全部。显示已应用条件，防止草稿与当前结果混淆。

每次读取至多 50 项，按创建时间和产物 ID 降序展示名称、类型、格式、字节数、创建时间及“查看产物”。“更多产物”显式追加下一页；刷新、应用和清除均从第一页开始，清理旧分页及详情。加载、空结果、分页失效、请求失败和当前访问不可用均使用独立反馈与明确恢复入口，不自动循环请求。

## 内容预览

选中卡片后，在页内打开“产物详情”，将焦点移到详情标题。详情请求固定携带完整 Project / Artifact / File 引用；列表观察不能替代内容请求的授权。详情展示正式返回的名称、描述、格式、大小、创建时间和 SHA-256，不显示内部 StoredObject 身份或存储位置。

文本按 8 KiB 请求单段，原样以纯文本显示；不执行 HTML、不自动建立外部链接、不加载外部资源。上下段仅按服务端返回的 UTF-8 字节边界显式读取；“重新读取”从首段重建范围。合法的零进展结果停止向后读取并提示重新读取，不自动重试。图片及一般文件引用只展示安全元数据与“此类型暂不支持在线预览”；无下载地址时不构造下载入口。无效 UTF-8 投影展示对应说明。

“返回产物列表”关闭详情并回焦原卡片按钮。加载时也可关闭或停止读取，离开路由、切换身份或项目后，迟到的列表和内容不能重新打开详情、覆盖新结果或夺焦。当前 401/403/404 均撤下本项目旧列表和详情，不把隐藏项目的 404 显示为空列表成功；恢复权限后通过“刷新产物”重新读取。Session 原请求实际退出前继续保持互斥。

## 新建文本产物

active 项目页首提供“新建文本产物”，以共享弹窗填写名称、描述、纯文本或 Markdown 格式及正文。输入按原样保存，正文显示 UTF-8 字节用量与上限；归档项目禁用新建。表单沿共享控件单列布局，操作按钮在窄屏换行。

发送后锁定原表单。结果不明时显示“查询原创建结果”；只有查询明确未观察到且项目 active 才显示“重试原创建请求”。处理中或取消待清理可显式“取消原创建”，完成清理后才显示已取消。不会自动重发、轮询或取消。

创建确认与当前读取分开反馈；实际读取列表和完整引用的正文后，可“返回产物”。读回失败提供“重读已创建产物”，不提供重复创建。离页、退出或关闭未决编辑前明确告知放弃本地不撤销服务器创建；返回键盘焦点到原入口，入口被重建时回到产物标题。
