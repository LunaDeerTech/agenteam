# 通用设置页面框架

> **v1 历史布局/业务参考。** 新页面设计以 [v2 页面蓝图](../redesign/page-blueprints.md)与[目标设计系统](../redesign/target-design.md)为准；下文旧视觉、宽度和占位要求不再作为重设计约束。业务字段和流程需核对当前架构、工作项及源码，不能仅凭本历史文档判定已实现。

> 适用：[系统设置](system-settings.md)、[个人设置](personal-settings.md)、[项目设置](project-settings.md)。

## 1. 页面职责与示意

```text
系统导航（项目设置另保留项目导航）
页面留白
┌─────────────────┐   ┌─────────────────────────────────┐
│ 一级 / 二级菜单 │   │ 当前栏目标题与说明              │
│ 独立悬浮面板    │   │ 列表 / 表单 / 详情              │
│                 │   │ 保存 / 取消                     │
└─────────────────┘   └─────────────────────────────────┘
```

“悬浮”指侧栏与页面边缘、内容区均有留白的独立面板，桌面不覆盖内容。滚动右侧时侧栏保持可见；菜单过长时侧栏自身滚动。尺寸、圆角和阴影复用[已确认样式](../styles/README.md)，不另设一套参数。

外容器、固定菜单宽度与表单行宽采用[统一设置模板](../interface-design.md#4-宽度对齐与密度)，不让左右区域自由按窗口比例拉伸。每个路由叶子提供一个清晰页面标题，字段分区使用下一级标题；目录型栏目再组合集合列表模板。

## 2. 栏目与默认选择

侧栏支持两级：一级可为分组或独立页面，二级为内容项。分组标题只展开 / 折叠；内容项才改变右侧内容。首个项目含子项时默认打开首个可访问叶子项并展开祖先。每类设置具体顺序见对应文档。

普通入口每次打开首项，不恢复上次页；指定设置项链接优先。一级及二级选中状态始终可辨识。不同设置页使用同一框架但不混合 scope。

## 3. 内容、字段及操作

右侧顶部为栏目标题和说明，下面按信息分区组织列表、表单或只读状态。列表提供创建、筛选、编辑 / 查看；字段注明可编辑、只读、敏感写入及条件可见。枚举和校验来自领域契约。

表单采用显式保存与取消；取消恢复服务端已保存值。保存中禁重复提交，成功展示反馈；失败保留输入。密码与 Credential 使用空白替换输入及“已配置”状态，不回显已有明文，空输入默认保留现有值，明确删除凭据时使用独立动作。

存在未保存修改时，切换菜单、离页或关闭编辑显示“继续编辑 / 放弃修改”；不默认丢弃，不自动提交。版本冲突保留输入，允许重新加载最新数据后再次编辑。

## 4. 加载及异常

列表、表单和只读运行状态独立加载。无内容显示对应创建引导；失败就地重试。权限变化关闭不可访问内容并显示说明。不可执行动作禁用并说明领域原因，不靠点击后的笼统报错解释。

删除、撤销等操作根据对象显示范围与后果，确认后提交；失败保持原列表并提示结果，不提前移除数据。

## 5. 窄屏与可访问性

侧栏转为覆盖面板，当前栏目提供打开菜单入口；选项选择后收起。表单改为单列，列表行允许堆叠。内容标题显示当前栏目；菜单层级可用键盘展开和选中。浮层遵循应用框架的焦点与关闭规则。
