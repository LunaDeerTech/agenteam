# 个人设置布局与栏目

> 框架：[通用设置](settings-shell.md)。账号与偏好业务来源：[账号生命周期](../../architecture/platform-infrastructure/authentication/account-lifecycle.md)。

## 1. 页面职责与示意

```text
系统导航
悬浮侧栏                    内容区
个人资料 → 基本资料         邮箱 / 用户名 / 显示名 / 头像
界面偏好 → 主题             跟随系统 / 浅色 / 深色
账号安全 → 密码 / 登录      修改密码 / 找回密码 / 退出登录
```

## 2. 主要栏目、字段与操作

基本资料默认首项：邮箱只读，用户名和显示名可编辑，头像可上传 / 替换 / 移除，保存 / 取消。用户名全站唯一，与显示名及邮箱登录分开；修改前提示本人项目路径会变化，旧链接失效且没有别名或自动跳转。重名/冲突保留输入，成功后使用当前路径。

没有头像使用默认身份标识；无显示名时导航显示邮箱。头像仅接受静态 JPG、PNG、WebP，大小与尺寸限制按服务端允许范围显示；不支持 SVG、动态头像或历史恢复。上传/替换失败如实反馈，不提前把未保存头像作为成功结果。

主题字段可选跟随系统、浅色、深色，默认跟随系统；复用已确认样式 tokens。预览与保存区分，保存到服务端账号偏好，取消恢复服务端已保存值；不以 Debug 内存状态或浏览器本地选择代替账号持久化，不增加语言、字号或通知偏好字段。

密码表单包含当前密码、新密码、确认新密码，提示统一密码规则；提交成功清空密码输入，并说明当前登录更新、其他旧登录失效。失败保留其他页面状态并提示原因。密码找回入口进入独立找回页面；退出登录结束当前 Session 并进入登录页，不自动停止后台 Agent 执行。邮箱首版不可修改，不开放二次验证或未定义的登录设备管理。

管理员初始密码建议在页面显示直达密码页入口；提示状态及普通用户注册密码来源遵循账号生命周期，不在布局另建规则。

## 3. 默认选择与导航

点击系统导航右侧用户显示名直接进入基本资料；指定个人设置项链接打开对应项。个人设置为系统页面，不保留项目导航。未保存修改遵循通用框架。

## 4. 加载及异常

资料与偏好分别加载，失败重试。密码输入不进入 URL 或普通日志；当前密码错误、两次新密码不一致、Session 失效提供明确反馈。未配置 SMTP 仍可找回密码，页面说明重置链接输出后台日志，具体流程见账号入口。

## 5. 窄屏

复用覆盖侧栏和单列表单；头像操作可换行，密码表单不横向溢出。
