# 个人设置布局与栏目

> 框架：[通用设置](settings-shell.md)。账号与偏好业务来源：[账号生命周期](../../architecture/platform-infrastructure/authentication/account-lifecycle.md)。

## 1. 页面职责与示意

```text
系统导航
悬浮侧栏                    内容区
个人资料 → 基本资料         邮箱 / 显示名 / 头像
界面偏好 → 主题             跟随系统 / 浅色 / 深色
账号安全 → 密码 / 登录      修改密码 / 找回密码 / 退出登录
```

## 2. 主要栏目、字段与操作

基本资料默认首项：邮箱只读，显示名可编辑，头像可上传 / 替换 / 移除，保存 / 取消。没有头像使用默认身份标识。注册时填写显示名；历史数据无显示名时导航显示邮箱。头像上传能力与限制由账号架构约束，页面按服务端允许范围显示。

主题字段可选跟随系统、浅色、深色；默认跟随系统。主题预览与保存区分，取消恢复原偏好；本轮不确定具体配色，不增加语言、字号或通知偏好字段。

密码表单包含当前密码、新密码、确认新密码；提交成功清空密码输入，失败保留其他页面状态并提示原因。密码找回入口进入独立找回页面；退出登录结束当前 Session 并进入登录页。邮箱首版不可修改，不开放二次验证或未定义的登录设备管理。

管理员初始密码建议在页面显示直达密码页入口；提示状态及普通用户注册密码来源遵循账号生命周期，不在布局另建规则。

## 3. 默认选择与导航

点击系统导航右侧用户显示名直接进入基本资料；指定个人设置项链接打开对应项。个人设置为系统页面，不保留项目导航。未保存修改遵循通用框架。

## 4. 加载及异常

资料与偏好分别加载，失败重试。密码输入不进入 URL 或普通日志；当前密码错误、两次新密码不一致、Session 失效提供明确反馈。未配置 SMTP 仍可找回密码，页面说明重置链接输出后台日志，具体流程见账号入口。

## 5. 窄屏

复用覆盖侧栏和单列表单；头像操作可换行，密码表单不横向溢出。
