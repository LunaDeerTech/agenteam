# 控件与交互样式

> 状态：2026-10-01 已定稿。上层：[样式规范](README.md)。业务条件、默认项和状态流转由布局与领域文档定义。

## 1. 公共参数与状态

| 参数 | 固定值 |
| --- | --- |
| 常规圆角 `--radius` | 7px |
| 大圆角 `--radius-lg` | 12px |
| 示例卡片圆角 | 8px |
| 边界 | 1px；装饰用 `--border`，必要识别用 `--control-border` |
| 焦点 | 2px `--focus` 实线，外偏移 3px |
| 单行控件高度 | 32px |
| 列表／树最小行高 | 36px |
| 下拉菜单项最小高度 | 36px |

default 保持主次操作与可辨识边界；hover 轻微改变表面或边界，不移动布局；focus 使用独立焦点环；selected 使用底色、文字及勾选等标记；disabled 禁止交互，弱化并保留原因；loading 保持上下文和等待文字、防重复提交；error 在字段或区域附近保留原因、输入及恢复动作。

系统导航链接不使用悬停下划线；悬停通过轻微灰阶底色和文字变化反馈，选中项也保留可辨识的悬停变化。品牌入口通过标记的底色与边界反馈，过渡沿用 `--motion`。

主要按钮使用 `--action-fill` / `--action-text`，普通按钮保留边界，文字按钮使用透明表面，危险操作使用危险语义。图标按钮须有可访问名称。卡片与普通内容分区不统一加重阴影；浮层使用 `--shadow`，轻抬升内容使用 `--panel-shadow`。

## 2. 选择、输入与开关

常规表单输入标签可见，placeholder 只作补充。消息输入器不显示“消息内容”标题，输入区使用透明表面、无内边框，聚焦时不增加高亮边框或轮廓；保留稳定的外层发送栏边界、光标、可访问名称和关联错误说明。错误通过 `aria-invalid` 和关联说明表达。只读保持可读及可选择文字，禁用禁止操作；敏感值按业务规则显示配置状态，不回显原凭据。

| 控件 | 外观与行为 |
| --- | --- |
| 复选框 | 17×17px，4px 圆角，选中显示勾选；多选语义 |
| Radio | 17×17px 圆形，7px 圆心，组内单选 |
| 开关 | 38×22px 轨道，16px 滑块，左右位移 16px；启用／关闭文字辅助识别 |
| 标签对齐 | 控件与文字垂直居中，间距 8px |
| 下拉选择器 | 显示当前值和箭头；选中项显示勾选，选择后更新并关闭 |

复选框、Radio、开关使用自定义外观，保留原生 input 的键盘、表单和禁用语义。开关用于即时的布尔状态；表单内实际何时持久化由业务决定，展示不新增保存契约。

下拉列表锚定在触发控件附近，宽度匹配控件并限制在视口内，空间不足向上展开。方向键、Home / End 移动，Enter / Space 选择，Escape 关闭并恢复焦点。Tab 关闭后允许继续页面导航；Vue 组件关闭列表后继续正常 Tab 顺序。

## 3. 文档树与内容组件

树的展开控件占位 24px，中心与连接线对齐；父节点图标作为缩进基准，子节点图标递进 16px。状态标签靠右，不改变名称起点。展开与名称选择独立，箭头转动，子树高度平滑过渡。

消息不使用头像：用户右侧、Agent 左侧，保留名称和时间，气泡正文左对齐。名称、身份和左右位置共同表达来源，不仅靠底色。消息间距和气泡尺寸见字体与密度规范。

卡片、列表、表格、引用、代码、折叠详情、标签、进度、加载、空状态和失败状态使用相同语义表面。运行详情默认折叠，折叠组件无外边框；正文默认最大高度 `min(320px, 40dvh)`，超过后在组件内滚动，可通过 `maxHeight` 调整；日志使用无边框代码展示，滚动区可以键盘聚焦。加载保留文字，失败保留恢复动作，空状态给出当前区域适合的入口。组件示例不定义正式搜索范围、运行能力或新增业务操作。

## 4. 操作反馈与间距

成功反馈在触发按钮上：例如“保存修改 → 保存中 → 已保存 → 保存修改”，配勾选标记，保持按钮宽度和焦点。成功文案展示 2400ms 后恢复，通过状态区播报；不使用屏幕底部成功提示。真实完成后才能显示成功，原型的 650ms 延迟只模拟等待。

对应内容同时更新。若触发按钮已消失，在原操作所属区域保留结果说明。失败不靠一闪而过的按钮文案，错误说明留在字段或区域并保留输入。危险动作需要明确确认，成功反馈不代替确认。

确认对话框的操作放在独立 footer：垂直内边距 16px、水平 20px、按钮间距 8px；窄屏垂直 14px、水平 18px。正文与 footer 各自保持内边距，禁止把两个按钮直接拼到正文段落后。身份标签和进度等相邻分区用 `--section-gap: 24px`；正文和辅助内容用 `--content-gap: 12px`。

## 5. 浮层用途、层级与焦点

| 用途 | 呈现方式 |
| --- | --- |
| 少量动作 | 按钮旁的锚定菜单；默认宽 200px，视口边缘至少留 8px |
| 值选择 | 锚定下拉列表，不与动作菜单混用语义 |
| 简短说明 | tooltip 或锚定说明；tooltip 不包含交互控件 |
| 搜索 | 独立输入与结果浮层，打开聚焦输入 |
| 对象详情 | 内联区或详情面板，位置遵循正式布局 |
| 确认、完整表单 | 模态对话框 |

模态和锚定浮层的 CSS 默认层级分别为 100、110。共享 useLayer 注册的模态、抽屉和锚定浮层统一按激活栈顺序分配绘制层级，以 100 为基数；较晚激活的层必须位于较早的层之上，不依赖 Teleport 节点的 DOM 顺序。关闭或移除后同步剩余层级，业务组件不得自行抬高 z-index。tooltip 在所属局部区域内使用明确层级，不能遮住上层模态。退出副本不可交互且从可访问树移除。

菜单支持方向键、Home / End、Escape、外部点击关闭；选择或 Escape 关闭恢复触发焦点。模态限制焦点，背景不可操作；关闭恢复原触发位置。Escape、遮罩和未保存修改的处理遵循业务后果，不能直接照搬原型的无条件关闭。

按钮使用原生 button；折叠用 Enter / Space；Radio 保留组内方向键行为。正式 menu、tree、tab 等组件必须配套完整键盘行为，不能只添加 ARIA role。错误和反馈使用适当的可访问状态区。

## 6. 动效

| token / 场景 | 固定值与表现 |
| --- | --- |
| `--motion` | 160ms：按钮、边界、选中、箭头和成功反馈 |
| `--motion-panel` | 200ms：对话框、详情面板、树和执行详情 |
| `--motion-exit` | 120ms：退出淡出及小幅回退 |
| `--ease` | `cubic-bezier(.2,.8,.2,1)` |
| 退出缓动 | `cubic-bezier(.4,0,1,1)` |
| 菜单／选择入场 | 淡入，向下 5px，缩放 .985 → 1 |
| 对话框入场 | 同类轻微位移与缩放，200ms |
| 详情面板入场 | 淡入，侧向 16px → 0 |
| 树／折叠 | 真实高度过渡，可连续点击中断，不排队 |
| Tab 切换 | 指示线平滑滑动；内容按前后方向横移 12px 并淡入／淡出，进入 200ms、退出 120ms，退出内容不可交互且不进入可访问树 |
| 其他内容切换 | 短暂淡入，框架不整体移动 |

避免弹跳、夸张缩放与持续装饰动画。动效不延迟业务请求；关闭立即恢复焦点。`prefers-reduced-motion: reduce` 下直接完成上述过渡，加载与反馈文字保留。
