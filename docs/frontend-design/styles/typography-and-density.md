# 字体与内容密度

> 状态：2026-10-01 已定稿。上层：[样式规范](README.md)。本规范固定组件排版，不确定业务页面区域尺寸。

## 1. 字体与标题

正文与标题使用系统无衬线字体，不依赖远程字体。中文说明与英文领域名称自然混排，代码、编号及运行标识使用等宽字体。

- `--font-sans`：`-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`
- `--font-display`：`var(--font-sans)`
- `--font-mono`：`'SFMono-Regular', Consolas, 'Liberation Mono', monospace`

标题直接呈现，任何情况下不使用 eyebrow（眉题）。分类由导航或明确字段表达，编号作为标注清楚的属性展示，不放在标题上方。字体回退允许字宽差异，不以固定字符宽度估算中文布局。

| 层级 | 字号 | 字重 | 行高 |
| --- | --- | --- | --- |
| 页面标题 | 26px；窄屏 23px | 600 | 1.35 |
| 分区标题 | 15px | 600 | 1.5 |
| 对象名称 | 14px | 600 | 1.6 |
| 正文与常规控件 | 14px | 400 | 1.6 |
| 通用辅助文字 | 12px | 400 | 1.6 |
| 消息名称与时间 | 11px | 名称 500，时间 400 | 1.6 |
| 代码与运行内容 | 12px | 400 | 1.6 |

标题不在每个容器重复出现；辅助文字使用 `--muted`，仍满足正文对比度。气泡正文左对齐，消息名称与时间的整组对齐随用户／Agent 来源变化。

## 2. 间距与密度

| token / 用途 | 固定值 |
| --- | --- |
| `--font-size` | 14px |
| `--line-height` | 1.6 |
| `--space` | 24px |
| `--section-gap` | 24px |
| `--content-gap` | 12px |
| `--control-height` | 32px |
| `--row-height` | 最小 36px |
| `--nav-height` | 46px 基础控件高度；多行时自然增高 |
| 标签、图标与文字间距 | 8px，文档图标与名称 7px |
| 消息组内相邻消息间距 | 20px |
| 消息名称与气泡间距 | 8px |
| 气泡内边距 | 垂直 12px，水平 14px |
| 气泡正文与代码间距 | 12px |

使用 4 / 8 / 12 / 16 / 20 / 24px 间距尺度。身份标签组到进度等下一个内容分区使用 24px；内容与对应说明用 12px；不同字段各自组织标签、帮助与错误，不能因某元素是 inline 而丢失分区间距。对话框正文和操作区分离，详见控件规范。

密度不通过强制等高裁掉文字。多行列表、按钮长文案与换行导航允许自然增高；控件高度是常规单行基线，不决定移动端最终触达区域。

## 3. 内容处理

- 列表和树：名称优先，属性与状态其次。树缩进表达父子关系，长名称截断时提供完整名称的可访问提示。
- 卡片和详情：标题自然换行，详情与正文保留完整内容，不为等高卡片隐藏标题。
- 消息：无头像，用户靠右、Agent 靠左；正文始终左对齐。名称与时间识别来源，代码不撑开气泡。
- 表单：标签保持可见，帮助和错误贴近字段；正文和操作区通过分区间距区别。
- Markdown、代码及表格：保留结构，长行或大表格在对应容器滚动；不引入整页横向滚动。

## 4. 窄屏与边界

使用 `min-width: 0` 及独立滚动容器，长标识可换行或局部滚动。展示消息内容桌面最大占行宽 88%，窄屏 94%；这是气泡内部样式，完整消息区宽度由正式布局决定。

组件布局在空间不足时允许换行、堆叠，关闭与输入入口保持可达。展示页 650px 以下使用窄屏样式；正式页面断点、侧栏、表单宽度和七列看板组织继续遵循布局文档，不以展示网格的 1100px 断点作业务约定。
