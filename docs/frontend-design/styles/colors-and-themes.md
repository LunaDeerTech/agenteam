# 颜色与主题

> 状态：2026-10-01 已定稿。上层：[样式规范](README.md)。以下为本项目 token，不宣称为 Linear 官方色值。

## 1. 配色与主题

固定使用石墨灰阶与低饱和、偏蓝的青蓝色。按钮填色较暗，强调文字及焦点在深色主题中使用同色相的较亮值；不把所有强调元素一起压暗，也不使用大面积高饱和背景。

产品支持浅色、深色和跟随系统，默认跟随系统。显式选择优先于系统偏好；仅跟随系统时响应 `prefers-color-scheme` 变化。首次可见绘制前应用有效主题，偏好尚不可读取时按系统主题渲染，避免闪烁。主题覆盖导航、正文、表面、表单、消息、菜单、详情、遮罩及反馈，不能只反转背景。

Vue Debug 默认跟随系统，手动选择仅影响当前应用会话，刷新重新跟随系统，不写入个人设置。正式偏好存储与接口由个人设置及前端实现专题定义，此处不新增契约。

## 3. 状态与身份

Task 的七种 state 保留各自名称与符号；进行中使用黄色 `--task-progress`，审查中使用独立 `--task-review`，受阻使用警告，完成使用成功，取消使用中性弱化并保留文字。优先级另行标示，不能复用 Agent 身份色。

Agent 身份点搭配名称，只表达身份；执行中的 busy、跳过、失败等事实使用独立状态标签。表中的三种身份色固定为展示样例，正式映射使用领域定义的 Agent tag-color，不新增映射协议。身份色可含紫色，不作为项目主题强调色。

索引 pending / processing 显示“索引中”，ready 显示“就绪”，failed 显示“索引失败”。成功、失败、受阻均有文字或图标，不能只出现彩色圆点。错误保留原因与恢复入口。

## 4. 对比度基线

正文及辅助文字至少 4.5:1；必要控件边界、状态图形、身份点和焦点至少 3:1。装饰线可更轻，禁用态可弱化但不波及可用控件及错误说明。透明背景按合成后的实际色值检查。深色 `--control-border` 在 `--accent-soft` 上不足 3:1，不用于该底色上的必要控件边界；选中控件使用 `--accent` 边界，输入保持规范表面。

当前不透明规定组合的计算结果：

| 组合 | 深色 | 浅色 |
| --- | --- | --- |
| 正文／面板 | 13.94:1 | 14.90:1 |
| 辅助文字／次级表面 | 6.10:1 | 5.11:1 |
| 按钮文字／按钮底色 | 5.78:1 | 5.14:1 |
| 强调文字／强调底色 | 5.67:1 | 5.06:1 |
| 控件边线／次级表面 | 3.28:1 | 3.28:1 |
| 焦点／次级表面 | 6.60:1 | 5.12:1 |

本轮核对 110 组组合，包含正文／辅助文字在各表面、按钮、语义标签、控件边界、焦点、状态和身份点；结果均通过。遮罩与阴影不是正文背景，不将这组计算作为透明叠层或未来业务页面的完整验收证明。

## 5. 使用与变更

外层、画布和卡片通过轻微亮度差表达层级；普通页面不覆盖参考营销截图的渐暗装饰幕。仅模态场景按需要使用遮罩。变更任何 token 后同步本文、CSS 和展示，并复查浅深主题及实际组合。
