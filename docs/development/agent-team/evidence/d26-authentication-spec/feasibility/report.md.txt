## 前端现状与必须补齐部分

- `web/src/router/index.ts` 仅开发 `/debug`、生产空 `/`、404；无 auth guard。`App.vue` 无条件包 AppShell，登录页需独立无已登录导航的布局。
- 没有 typed API client、Session 状态、CSRF 管理、登录/注销页面。`SystemNav` 仅从 route meta 读入口，不含真实用户或退出动作。
- 可直接复用 UiField/UiInput/UiButton/UiState/UiSpinner/UiCard、现有布局/tokens、`useTheme`。当前主题仅内存 system；Session 已返回真实 `user.theme`，可只读应用，偏好编辑/保存留后续，不能将 Debug 选择写成账号偏好。
- 产品 web 锁定 Vue 3.5.43、Vite 8.3.1；没有 go-captcha-vue/Playwright。既有独立 harness 锁定 go-captcha-vue 2.0.7、同版 Vue/Vite 和 Playwright 1.56.1。正式旋转组件需要按已定依赖核准 web 的 package/lock 窄增量，不能 import harness/Debug 或复制其 `/fixture/*` 客户端充当产品 API。
- harness 的原组件缺键盘/ARIA，因此其同题 range 控件、焦点恢复经验必须在正式包装中重验。保留视觉挑战限制，不声称已解决不可视用户可达性。

完整页面结果不能只有密码正确时成功。需要处理 `CHALLENGE_REQUIRED` 与普通 401 的区别、挑战过期/错题/换邮箱或登录 key、双击/取消/异常/Unknown，密码不 trim、不截断、不持久化。匿名 CSRF 与 Session CSRF 不能混用：login 200 没有 Session CSRF，随后真实 GET session 才取得它。Cookie 由浏览器 HttpOnly 管理；client 用同源相对 `/api/v1`，不读取/复制 Cookie、不存密码/pass/CSRF 到 URL 或持久存储。

同一待查登录保留原 key 与完整输入意义；改邮箱/密码是新意义，挑战/pass 的正式绑定不能乱换。没有公开 HTTP command-lookup 路由可虚构调用；Unknown/响应失败保持未确认，按既有同键恢复及当前 session 事实收敛，不换 key 自动重发、不显示成功。logout 未确认不能仅清前端缓存宣称服务端已撤销。迟到 session/login 响应不得在已退出/切换身份后恢复旧状态。轮询/页面保活不自行续期。

## 页面范围与托管边界

已有产品规则足以提供登录落点：`layouts/system-pages.md` §2 明确系统首页仅“首页”标题和待设计 Dashboard 容器，不造统计、项目列表或 Inbox。可将真实登录落到这个既定首页；它不是测试 Session 面板。认证解析前不显示管理员菜单/旧用户内容。只实现已有登录及首页基础路由和真实 logout 动作，return target 限实际已实现路由并重新校验；不将登录等同 Project Owner 授权。

邀请、找回/重置、首次改密入口、个人设置及完整系统导航属于已确认后续页面，不是未定产品规则。窄卡须明确本块未实现范围，保留初始密码的非强制建议，**不新增导航含义、不生成假的可点击入口/未完成设置页、不把任意项目目标重定向成另一项目**。页面命名/路由及延期入口如何呈现由下一工程卡按既定布局明确，本分析不代写产品导航。

当前 Central `app/app.go:162` 只分发 diagnostics 和 Account handler，不提供静态资源/SPA fallback；Vite 配置没有 API proxy。因此不能开 5173 页面后直接跨源请求 backend，或擅加 CORS、Cookie、Host/Origin 例外。

建议沿主线程指定边界：同源相对 API；开发代理与验收用同源前端服务只转发 `/api/v1` 到真实 Account HTTP，保留正确 Host/Origin，`PUBLIC_ORIGIN` 固定为浏览器外部 origin。前端资源/History fallback 与 API 错误严格分开。生产同源静态托管归部署/根集成责任，当前不改 Central、不宣称 `/login` 已可由 Central 单进程提供。D26 本段没有把 Central 嵌入静态服务写成每张子卡的硬门槛，故此边界足够形成真实前端库/页面完整结果；若交付定义要求已部署的单入口整站，则静态托管/SPA fallback 是尚缺的硬集成项。
