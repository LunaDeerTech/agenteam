## 实施依赖与结论边界

候选路径可以表达完整增量，但当前没有实施写权。必须先由 root 接受 tools 产品并固定实际依赖提交，停止四个共享 adapter 文件的原作者写入，再核与本规格固定基线的差量、授予单一作者。当前 tools 独立动态验收停止，不能把它作为已通过依赖；规格静审不解除该停止条件。

本规格保持单次 wire exchange，未绑定 Resolver 的 Anthropic 能力、应用调用、DB writer、ProcessGuard、Project 生命周期或工具执行；ToolComplete 不构成执行授权。完整 D09 及其他既有阻塞项不因此完成。
