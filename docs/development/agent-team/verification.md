## 演练发现与修正

- 首次使用 `--ephemeral` 的临时会话创建子线程时出现 `no rollout found for thread id`；该次不计为通过。改用正常只读会话后，自定义角色实际运行成功。
- 当前客户端没有关闭子线程的工具；强制“必须关闭”会阻塞角色交接。[团队流程](README.md)现以确认完成和停止写入为前提，关闭接口可用时才关闭；若运行时仍拒绝下一位则恢复新会话，不放宽并发。
- 验收角色一次 heredoc 命令被只读沙箱拒绝，改用 `-c` 后解析成功；其额外断言错误地要求文件名等于角色名。主线程按真实文件和 TOML `name` 字段复核通过，并在团队文档与验收技能中明确这个区别。
- 只读沙箱中 Git 有 xcrun 缓存写入拒绝警告，但只读检查输出有效、退出 0；主线程在实际工作区复核。命令失败和警告保留为演练记录，没有误报为完全无错误运行。
- 主线程审查时补充了允许只读 Git 检查，以及“未授权的新依赖才返回主线程”的准确表述。
