## Original-request binding and capture

The native fetch wrapper delegates exactly once and returns the original Promise. It observes the same Response, stream and actual reader using separate handled branches that return each original read/cancel Promise unchanged. It never calls read/cancel/release itself, clones/tees a Response, saves byte contents, decodes another body, issues HTTP, or fabricates a successful read. Registration occurs before the original UI actions and survives each fresh document via the init script.

Capture only the fixture's fixed public Project/resource paths in the existing closed Work endpoint classes, capped at the existing 256-observation bound. Each fetch gets a private document-local sequence. Native and Playwright evidence become joined only when exactly one original PW Request/Response and one native observation agree on unique valid response X-Request-ID, method, exact public target and document. Duplicate/missing ID, repeated matching attempts or document ambiguity stays unbound. Never infer a match from array position or a later retry. The unforwarded response without an upstream ID remains explicitly unbound for native correlation; its existing declared-request evidence is separate.

Safe counters follow Model's diagnostic projection: headers/status, read calls/settlements/rejections, observed byte total, actual done:true, reader/stream cancel call/settlement/rejection counts, release calls/successes, original signal abort, and browser-local operation order. Content-Length is comparable only when valid, Content-Encoding is absent/identity, unique binding holds, and done:true precedes every observed cancel/abort/read rejection. A read resolving done after cancellation does not establish EOF. Node event times and browser operation order remain separate clocks.

Use one 250ms single-flight page.evaluate sampler starting before UI actions, independently of the existing original response.finished waits. Preserve its last safe snapshot throughout those waits and across page navigation; at each document boundary retain the old document's last sample as nonfinal. No second evaluate starts while the previous one is pending. Stop clears its timer/listeners and waits for the current diagnostic branch for at most the existing Model 250ms bound; a lost/unfinished evaluate remains `sample_join_unavailable`, never joined. At normal finish or failure, restore only wrappers still owned by this observer, detach abort/DOM/event listeners, and record explicit hook-retirement/end-snapshot status. A 45s document observation expiry only retires hooks; it never cancels the production request. Any pending native callback keeps only its bounded counters until its original operation settles; it cannot issue a new read.
