# agenteam 环境与运行时排障

供 `platform_worker` 及遇到环境、进程问题的实现者和验证者使用。先读[当前分支记录](../../../.agent-state/current.md)、目标任务与[环境恢复入口](../../../docs/development/agent-team/recovery-2026-10-08-environment.md)，再按需读[后端](../../../docs/development/backend/README.md)或[前端](../../../docs/development/frontend/README.md)说明。历史环境记录只提供线索，本次能力须实测；公共权限与交付沿[团队流程](../../../docs/development/agent-team/README.md)。

## 触发与产物

用于缺源码/harness、错误工具链、fixture 启动失败、网络/浏览器不可用、进程退出不完整、超时和有明确指标的性能退化。产物是最小能力结论、可执行重建或复现步骤、根因与修复，或下一条有判别力的检查；避免收集无关全机清单。

## 先判定缺的是哪一层

1. 核 Git 基线、目标文件、锁文件与实际差异。必要源码未找到时，先查对应路径历史和当前任务分支；旧报告、二进制或哈希文字不能替代源码。按规格重建要明确标为新实现。
2. 按当前任务列出必需能力及最小探针：Go 精确版本/编译，Node 与锁定依赖，Docker daemon/固定镜像，浏览器 executable/最小启动，fixture 配置/实际连接。只测相关项，不一次启动整套产品。
3. 用 `GOTOOLCHAIN=local "$AGENTEAM_GO" version`、`node --version`、对应包锁和实际 executable 确认版本；工具路径以本机实际发现为准。可解析配置、存在二进制与服务真正可用分别记录。
4. 在任务已有授权内恢复缺少的固定依赖或任务所有资源，复用仓库脚本。旧 onboarding 可能包含过时版本和服务操作，先核内容与当前契约再选择步骤；不凭环境缺失修改全局 trust 或替换版本。

## 用最小实验排除假设

先给出精确症状、预期行为与一个可重复命令。沿源码/构建产物、工具启动、fixture、网络协议、业务断言、结果收集逐层缩小范围，找到第一个与预期不同的可观察事实。

每轮只改变一个与假设有关的条件，记录预测、实际结果和下一步。启动失败优先检查退出码、stderr 与对应前置；已有故障边界时用更小场景复现。没有新证据就更换诊断方法或报告具体缺口，不重复运行昂贵测试、扩大预算或重试受阻外部通道。

必要复现脚本、参数和脱敏输入保存为仓库内普通文件，按[检查点说明](../../../.agent-state/README.md)主动交出；可重新生成的 stdout、trace、profile 留在忽略目录。缺失外部输入或不可恢复原件如实保留，不重建虚构的历史证据。

## 卡死、取消与资源终态

从本任务登记的进程、容器、连接或资源 ID 开始，核对应命令的实际 session 与 PID 身份，再看阻塞的等待链：请求、callback、Rows、worker、数据库或对象关闭。结合本任务的堆栈、日志和服务端事实判断等待谁释放什么，不依据名字匹配或宿主机全局数量推断所有权。

核截止时间是否从同一总预算传递，取消信号是否送达，调用是否真实返回、join 和 wait/exit。必要的 drain/force、ProcessGuard 持有和数据库关闭顺序以[进程契约](../../../docs/development/backend/README.md#停止与退出)为准；取消成功不是资源已退出。只终止、删除已核实属于本任务的资源，保留退出码与失败事实。

## 有指标的性能定位

先固定目标指标、工作量、环境与可重复基线，例如延迟分布、吞吐、分配量或锁等待；确认重复测量能够区分信号和噪声后，再按症状选 CPU、heap、block/mutex profile、trace 或查询计划。观测和压测使用任务所有环境，profile 可能包含敏感数据，保存前检查内容。

从实际热点提出单个可验证修正，使用同场景比较前后并核对功能与资源边界。没有基线或实际 profile 时只报告假设；没有性能问题的任务不因此增加优化或基准项目。

## 交付边界

给出已证明的环境能力、根因/修复、实际命令和受影响验证，明确仍缺什么；环境探针通过不代表产品通过。业务测试重建用[测试工程技能](../agenteam-test-engineering/SKILL.md)，事务问题用[数据库技能](../agenteam-database/SKILL.md)。交付前暂停必要文件写入，列出仍运行命令与实际自有资源终态，范围外依赖或未决规则交直接负责人。
