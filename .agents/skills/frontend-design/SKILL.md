# 前端视觉设计与组件品质

本文件是 agenteam 项目适配入口，不是上游原版技能。已审读的 Anthropic 原始技能保存在 [固定设计参考](reference/frontend-design.md)，来源、提交和校验值见[技能来源](../../../docs/development/agent-team/skill-sources.md#前端设计与-ux-审查技能)。读取该参考时按下列适配范围使用；不自动获取远端新规则。

## 规则与适用边界

- 用户明确选择的 Linear 官方产品参考和已确认的项目方向优先；重设计使用[设计规范 v2](../../../docs/frontend-design/redesign/target-design.md)与当前[页面蓝图](../../../docs/frontend-design/redesign/page-blueprints.md)，组合[重设计编排](../agenteam-frontend-redesign/SKILL.md)。旧布局、样式和 CSS token 是待迁移现状，不锁定新规范的字体、颜色、尺寸或页面结构。
- 采用上游关于任务驱动的信息层级、明确排版、克制装饰、用户可理解文案、自查截图和真实状态的建议。调色板、字体及共享 Ui 控件按新规范和完整页面样板决定；不为追求上游所谓独特品牌偏离 Linear 产品方向。
- 避免无信息用途的装饰眉题；上游提到眉题、hero、品牌表现、自动播放或页面揭示动效，不是为本产品增加这些元素的要求。动效服务用户操作并遵循减少动效偏好；成功与错误反馈按新规范归属具体任务，同时保留业务状态契约。
- 不按上游占位文案建议编造业务能力、统计或可用动作；文案与状态来自真实领域规则。新依赖、字体下载、图片获取和组件接口变更仍受任务授权及唯一写者约束。

## 工作方法

1. 明确当前页面的用户任务、主要对象和下一步动作，按新规范与当前蓝图选择页面、弹窗或抽屉。重设计先验证完整页面样板，再提炼可复用框架与组件；复用[前端实现技能](../agenteam-vue-development/SKILL.md)与[公共组件接口](../../../docs/development/frontend/components.md)，按任务范围增强现有控件。
2. 用简短文字或线框说明主要信息、次要说明和技术细节的层级。技术标识、配置项和诊断信息按任务需要渐进展开；关键风险、权限、错误与下一步不能被折叠隐藏。
3. 检查标题、内容宽度、对齐、留白、分隔与主次动作，消除没有信息用途的重复卡片、徽章、边框和说明。调整使用新规范确立的语义 token 与组件；迁移按共享层唯一 owner 协调，避免为单页另建样式系统。
4. 在同一用户流程中核对正常、空、加载、失败、权限、等待、取消以及适用的冲突/结果未知/恢复状态；按钮文案说明真实结果，失败说明可执行的下一步。缺失业务能力如实记录。
5. 对照截图或实际页面复核浅深主题、窄屏、长内容和组件状态。键盘、焦点、异步反馈与无障碍细节结合 [UX 审查技能](../web-design-guidelines/SKILL.md)；真实浏览器方法仍用[测试工程技能](../agenteam-test-engineering/SKILL.md)。

## 交付

按任务授权输出有位置和依据的发现、简短设计决定或实现结果；区别规范违反、可用性问题和审美建议。说明截图来自真实业务还是 fixture、实际检查范围和未验证状态。静态设计建议及作者自查不代表浏览器交互或业务验收通过。
