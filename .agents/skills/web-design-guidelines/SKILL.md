# 前端交互与无障碍审查

本文件是 agenteam 项目适配入口，不是 Vercel `agent-skills` 的原版技能。采用有明确 MIT 许可的 [Vercel Web Interface Guidelines 固定参考](reference/web-interface-guidelines.md)；原文完整保留，提交、来源与校验值见[技能来源](../../../docs/development/agent-team/skill-sources.md#前端设计与-ux-审查技能)。使用本地参考，不在每次审查时获取 `main` 或执行远端安装器。

## 审查范围

先读取任务指定页面/组件、[设计规范 v2](../../../docs/frontend-design/redesign/target-design.md)、当前[页面蓝图](../../../docs/frontend-design/redesign/page-blueprints.md)及真实业务状态规则。重设计的完整页面门槛与返修使用[重设计编排](../agenteam-frontend-redesign/SKILL.md)。按当前用户流程选择参考中的可访问性、焦点、表单、内容溢出、主题、导航、交互和动效规则；已明确任务范围时无需再向用户索要文件。

1. 主动作、返回/取消和当前状态应可发现、可理解；次要技术细节逐步展开，失败、权限与恢复信息在对应区域可见。
2. 优先原生语义和共享 Ui 组件；检查可访问名称、可见标签、键盘行为、焦点可见性及浮层关闭后的焦点恢复。异步结果按实际变化和用户影响使用合适的 live region，避免重复播报。
3. 检查输入与错误关联、提交等待、保留输入、长文案、空列表、滚动职责、窄屏及浅深主题；操作反馈与业务最终事实一致。破坏性操作和未保存变更遵循对应业务契约。
4. 静态源码只能证明相应实现事实；键盘、焦点、减少动效、缩放和溢出需适用的浏览器证据，方法见[测试工程技能](../agenteam-test-engineering/SKILL.md)。已有稳定证据可复用，未检查的状态标为未验证。

## 将上游规则用于本项目

- 用户选择的 Linear 产品方向与设计规范 v2 优先；旧 token、密度、控件和反馈样式是迁移输入，不能充当新设计合格标准。规则中的 Tailwind/React/Next.js 示例只表达原理，不引入对应依赖。Vue 原生控件已有键盘语义时不重复添加按键处理；`v-model` 不按 React 的 `onChange` 检查方式判错。
- 原文的英文 Title Case、引号、占位符省略号等文案偏好不覆盖中文表达及项目术语。技术值按用途显示；不把协议格式或标识符强制改成人类语言格式。
- `autocomplete` 按字段用途设置，不统一关闭所有非认证字段；提交按钮是否可用由验证、权限及请求状态决定。原文建议不能覆盖已有防重复提交或未知结果恢复规则。
- URL 同步仅用于已定义的可分享导航状态，不将 Secret、表单输入或瞬时内部状态写入 URL；破坏性动作确认与撤销按真实业务能力实现。
- 列表是否虚拟化按实际渲染成本、可访问性和已存在分页决定，不以超过 50 项直接判错或安装依赖。未经测量的性能建议不报告为已证实瓶颈。
- 溢出应找到内容与布局原因，不以 `overflow-x: hidden` 掩盖裁切；动效属性、自动聚焦、滚动链与拖动期间 `inert` 按实际交互和焦点验证，不机械套用示例。

## 输出与证据

每项发现给出文件/行号或页面与状态、用户影响、规则依据及可执行修正；区分确定缺陷、设计建议和待浏览器验证项。按影响排序并保留检查范围与证据限制，不因上游要求简短输出而省略关键条件。纯截图不能证明键盘、辅助技术或业务调用通过，fixture 展示不能证明生产集成完成。
